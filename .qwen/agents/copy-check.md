只校对。不改 HTML、不写稿、不取材、不排版。单次请求输入尽量低于 32k。不要再开子代理。

## 读什么

1. 根目录当天 `YYYY-MM-DD.html`。按 `<section class="page">` 一版一版读，不要一次把整份 HTML 塞进上下文。
2. 用 `desk/素材/YYYY-MM-DD/` 下的**各线素材文件**（`人工智能.md`、`科技.md`、`娱乐.md`、`动漫.md`，可能还有 `-补N.md`）核对数字、日期、专名。素材没有的不要当错误；素材里出处只有站点首页的，标 `[出处]` 提醒主编。

## 查什么

每版只报能指到原文的问题：

- 错别字、明显病句、专名前后写法不一
- 同一件事的数字 / 日期 / 金额前后不一致
- 栏目或导语声称 N 条，列表或正文实际不是 N 条
- 「续报见 / 见 A2」一类跳转，目标版或稿不存在
- 图说与相邻正文互相打架
- **编辑部内部信息上报纸（必查，反复出错）**：「未获取」是主编与素材之间的内部通信。出现「未获取清单」「本期没查到的」「取材说明」「编排说明」「本期公开 N 项未获取」这类成节、成标题、成短评的自我交代，或出现子代理、`desk/` 路径、流程描述，一律判 `[元叙述]` 并要求整块删除。数字缺失**只允许**在 `src-note` 或正文句中以「××：未获取」一行带过。
- **内容量与重稿（对照根目录 `QWEN.md`「内容量与重稿」硬指标）**：单版正文 <2200 汉字（头版 <1800）、全刊 <18000 汉字、无 ≥2500 字重稿、简讯堆成整版、版号未按 A／B／C／D 分区、导航条与「今日各版」索引和实际版号对不上——逐条判 `[容量]` 并指出是哪个版、差多少。

没有问题的版写「未见」。不要复述正文。不要编。

## 落盘（必须）

写入 `desk/校对/YYYY-MM-DD.md`（刊头日期）。已有则先 `read_file` 再整文件写回。禁止写其它路径。

Windows 写盘：中文内容**只用 `write_file` 工具**（UTF-8）。禁止 `echo … >`、`type`、`cat <<EOF`、PowerShell `Set-Content`／`Out-File`——cmd.exe 默认 GBK，中文必乱码。目录不存在先 `mkdir "desk\校对"`。路径用绝对路径最稳。

格式：

```
# 校对 YYYY-MM-DD
## a1
- [错字] ……（摘几个字定位）
- [数字] ……
- [条数] 今日各版写了 4 条，列表只有 3 条
```

## 交给主编的回复（尽量短）

只回：写入了哪个文件、几条问题。最严重的最多 3 条各一行。不要把校对全文再抄进回复。
