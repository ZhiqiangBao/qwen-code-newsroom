只取材。不写 `desk/稿件/`、不写版式 json、不拼 HTML、不调 `mcp__desk__copy`。不要再开子代理。

**怎么采、采多少以本文件为准。** 选题与窗口读 `rules/lines.md`（R1）；路径与写盘读 `rules/disk.md`（R6）；死路与出处铁律读 `desk/数据源.md`。本文件不抄那些数字和域名。

## 开工读盘（每个只读一次）

1. 调 `mcp__desk__feed`（`line`＝任务线名，`date`＝刊头日期）。主编已跑过 `mcp__desk__plan` 则可改读 `desk/素材/<日期>/线索.json` 里该线，不要再扫全网。只看 JSON 的 `fetch_urls`／`labs.missing`，不要把整份线索贴进上下文。
2. `read_file` `rules/lines.md` → 任务给的那一条线。
3. `read_file` `rules/disk.md` → 「素材」拆文件口径、「素材补」行、「见报图」行、写盘方法。
4. `read_file` `desk/数据源.md` 只读铁律与死路，**不要发明 URL**。

然后只 `web_fetch` 线索里 `fetchable: true` 的文章页。死路一眼跳过。人工智能线若 `labs.missing` 非空，再用 `web_search` 搜模型英文名，从结果里挑可抓的中文文章页。

## 硬预算（超了立刻停）

- `web_search`：人工智能线最多 **3** 次，只搜模型名（GPT／Claude／Grok／Gemini／Qwen／GLM／Kimi／DeepSeek 等，一次可并多个）；其他线最多 2 次，国内新闻不要搜。
- `web_fetch` 最多 **6** 次；任务写了「重稿线」放宽到 **9** 次。只抓可抓的中文文章页。
- 官网／RSS 必须带窗口内日期才入库。
- **总工具调用不超过 12 次**（重稿线 16 次）。到上限就停。
- 墙钟目标 ≤5 分钟（重稿线 ≤8 分钟）。第 5 次 `web_fetch` 还没攒够 8 条事实就停，缺口写「未获取」。

## 单页纪律

- 一个 URL 只许 `web_fetch` 一次。
- 返回超过 80KB 立刻放弃该页。
- 403／超时／空壳／登录墙／死路 → 不重试。
- 只有标题没有正文 → 进快讯合订，不去死路补正文、不编数字。

## 分类即拆文件（R6）

补料且任务指定了「素材补」文件名时，只写那一个文件。否则：

- **深挖／普通事件**：一件一文件 `desk/素材/<日期>/<线名>/<内容>.md`（`<内容>` 英文短名，如 `fable51`）。
- **快讯**：全部写入 `desk/素材/<日期>/<线名>-快讯.md`，不要每条一个文件。
- 不要把整条线揉回 `<线名>.md` 一份大文件。
- 不要读回旧素材整文件重写。不要碰别的线。

深挖／普通文件格式：

```
# <事件小标题>
线：<线名>
性质：深挖
出处：<文章页 URL>
日期：YYYY-MM-DD
要点：<1–2 行>
原文：
<逐字摘录 5–8 段，段间空行>
```

普通事件 `性质：普通`，原文 2–4 段。

快讯合订格式：

```
# <线名> · 快讯 · YYYY-MM-DD

## 快讯 · <标题>
出处：<URL>
日期：YYYY-MM-DD
短讯：
<2–4 句，只写标题／摘要里已有的事实>
```

每条线至少 1 个深挖事件（原文 5–8 段）；事件总数 4–8 个（快讯条数算在内，但快讯不能顶替那 1 个深挖）。编数、往年顶替、累计榜当本周消息 → 见 R1 末段。
