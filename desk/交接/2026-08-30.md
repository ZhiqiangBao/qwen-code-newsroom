## 2. 现在还剩什么活（按优先级，做完就算出刊）

**P0 — 版式：把每一版从 grid 改成整版连续分栏。**
当前只有 C1 用了 `.flow`；A1/A2/A3/A4/A5/B1/B2/D1/D2 仍是 `<div class="row"><article class="c4">…<article class="c2">…</div>` 的网格结构，边栏比正文短就整列留白——这是用户反复退回的唯一原因。

做法（已在 C1 上验证过的 CSS，直接复用到各版）：

```css
.flow{column-count:3;column-gap:15px;column-rule:1px solid var(--hair);
      text-align:justify;text-justify:inter-ideograph;padding-top:10px}
.flow article{margin:0 0 11px}
.flow h2,.flow h3,.flow .kicker,.flow .deck,.flow .by,.flow .rule{break-after:avoid}
.flow table.stat,.flow .box,.flow .ed,.flow figure,.flow .q,.flow .idx{break-inside:avoid}
.flow figure{float:right;width:44%;margin:2px 0 9px 14px}
.flow figure.wide{float:none;width:100%;margin:0 0 9px}
```

- 每版把外层 `.row` 换成 `.flow`，去掉 `class="c2/c3/c4/c5/c6"` 与 `.vr`（竖线由 `column-rule` 提供）。
- 文章内部的 `<div class="cols">` 一律拆掉，正文直接单栏流（多栏套多栏必出错）。
- 头版大标题要跨栏就用 `column-span:all`。
- **绝对不要给 `.flow` 的直接子元素加 `display:inline-block`**：多栏容器里的 inline-block 不可断栏，长文会被整块推到下一栏，全版塌成空洞（前任就是这么把版面搞坏的）。

**P1 — 每版填满到等高。** 目标纸高 1250–1650px（960px 视口下）。2026-08-30 现状实测：A1 1603 / A2 1225 / A3 1279 / A4 1298 / A5 1379 / B1 1622 / B2 1312 / C1 1209 / D1 1271 / D2 未测。改完 `.flow` 后栏高自动配平，只需按 `版式-2026-08-30.md` 的正文预算补字或删字。

**P2 — 图文绕排。** 凡是"图 + 文"的地方，图用 `float` + **单栏正文**（`.just`），不要用 `.cols` 包正文——多栏容器里 float 只影响所在栏，会在图下方留空洞。B1 的景甜稿已按此改过，可当范例。

**P3 — 海报不许裁。** 官方海报/剧照一律 `object-fit:contain; max-height:none`，宁可占一整栏也不能切边。
