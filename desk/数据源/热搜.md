# 热搜（常设地址表，不是每期生成）

热榜接口写在 `desk/feeds.json` 的 `hot` 段。`mcp__desk__plan` 每期抓一次，结果落在 `desk/素材/<刊头日期>/榜单.json` 与 `线索.json`。

**`fetch` 不读本文件。** 不要 `web_fetch` 这些 JSON 或微博 HTML。

| 用途 | 地址 |
|---|---|
| 微博热搜 JSON | https://weibo.com/ajax/side/hotSearch （线索，不算出处） |
| 百度热搜／电影／电视／财经 | `top.baidu.com/api/board?tab=` `realtime`／`movie`／`teleplay`／`finance` |

改热榜源只改 `feeds.json`，不必每期重写本文件。
