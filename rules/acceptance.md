# 发行验收

编辑台交出候选页、完整指纹和逐版校样。校对员执行整期检查，主编核准同一指纹后发行。每次改稿、换图或重排版位都需要重新生成候选，以新指纹核对受影响内容。

## 自动检查

校对员调用 `mcp__desk__review(date)`，核对实际成报的以下项目。

- [篇幅与版位](volume.md)规定的 8–10 版、版号顺序、导航、全刊至少 18,000 字、逐版正文量、稿件份数和快讯位置。至少一篇分析或深挖正文满 2,500 个汉字，独占双栏版位。
- [配图规则](visual.md)规定的 2–5 张文章配图。每张图有替代文字和图注。浏览器需成功显示图片。
- [版面验收](page-size.md)规定的 912 CSS 像素纸宽、每版高宽比 1.35–1.75、底部哨兵、内页版头及可识别的图片裁切。超过上限和低于下限均为发行阻断项。
- 文章与入选证据一致，出处在对应文章里可点击。校样文件、页序和成报指纹须与整期量尺回执一致。

`ok` 为 `false` 时，按 `issue.errors` 修稿量、版位或配图，按 `errors` 修具体版面的尺寸和裁切。缺证据就补原件。纠正后重新生成候选并复核。

## 主编终审

1. 打开实际候选和逐版校样。逐条核对关键日期、单位、引语、证据范围和图表数据。清除编辑备注及无法落到证据的推断。核对图片属于对应新闻，读者能看懂图注、数据和出处。
2. 逐版查看报头、主标题、导语、正文到出处的阅读顺序。测量各栏最后一行之间的最大高差以及一栏宽度，按同一单位记录。检查图片和文字的裁切、遮挡、变形以及图注是否脱离图片。
3. 在 320 CSS 像素的视口打开候选。逐版查看单栏顺序，确认导航、出处链接和图表可用。达到全部条件后保存 `desk/版面/刊期/终审.json`。

| JSON 字段 | 填写内容 |
|---|---|
| `fingerprint` | 最终候选的完整指纹 |
| `reviewer` | 实际验收人 |
| `editorial` | 核对通过后将 `facts`、`prose`、`image_rights` 分别记为 `true` |
| `desktop` | 以实际小写版号为键，每版填写 `reading_order`、`captions`、`no_clipping` 的验收结果，以及 `column_bottom_gap_px` 和 `column_width_px` 的实测值 |
| `mobile` | `width_px` 为 320，实际通过后将 `reading_order`、`navigation`、`source_links` 记为 `true` |

发布人使用 [README 的发行入口](../README.md#核准发行)，同时传入完整指纹和终审记录。自动检查、整期校样和主编终审全部通过后，程序更新首页及日期归档。发布人再打开线上首页和归档确认读者看到的是同一份成报。
