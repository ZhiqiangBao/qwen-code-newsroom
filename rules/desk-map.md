# 编辑台目录

日期一律用刊头日期。

| 用途 | 路径 |
|---|---|
| 线索、素材、行情 | `desk/素材/YYYY-MM-DD/` |
| 定稿前核过的证据 | `desk/证据/YYYY-MM-DD.json` |
| 稿件与目录 | `desk/稿件/YYYY-MM-DD/` |
| 版式 | `desk/版式/YYYY-MM-DD.json` |
| 图片 | `img/YYYY-MM-DD/` |
| 校对 | `desk/校对/YYYY-MM-DD.md` |
| 日期版 | `YYYY-MM-DD.html` |
| 候选页与导出 | `desk/版面/YYYY-MM-DD/` |
| 读者首页与历史期 | `docs/index.html`、`docs/YYYY-MM-DD.html` |

采集缓存、候选目录和量尺回执是本地文件。候选的实际网页在 `desk/版面/YYYY-MM-DD/候选/index.html`。首次发行某期之前，旧首页保持可用。
