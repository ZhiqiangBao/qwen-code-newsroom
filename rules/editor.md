# 主编规程

## 选题与证据

1. 确认刊头日期，再调 `mcp__desk__plan`。读来源的状态与候选链接。超时或降级时让该线改查固定来源或做定向搜索。正常无新稿的来源可以跳过。
2. 五路取材用 `fetch`。任务给工作区绝对路径、采访线、日期与待补问题。收回材料后打开入选候选的原始出处。日期区分事件发生、公告和报道。两篇转述沿用同一原始出处时登记同一个来源链标识。
3. 先定头条和一篇分析，为重稿补齐时间线、多方表态和可比数字，再按[篇幅与版位](volume.md)核对整期备稿量。逐条登记事实和原始出处。确定能刊登的稿件后，将合规 JSON 交给 `mcp__desk__select`。[证据表格式](evidence.md)

## 写稿与核对

1. `mcp__desk__copy_lineup(date, from_materials=true)` 按入选证据表写稿。同一时刻只运行一项写稿请求。为已核证据充分的重稿，可用 `mcp__desk__copy` 给对应 ID 指定 `chars=2600`。证据不足以写到目标时先补原件。单篇稿出错时只修受影响稿件。
2. 请 `copy-check` 对照证据表和原件读标题、导语、正文、引语与图表数据。高风险稿必须核到独立来源和当事方回应。主编精读头条、分析及高风险稿，处理未解决证据问题。证据不足时移除该稿或降低体裁，更新证据表并重新生成受影响的稿件。
3. 交 `makeup` 按真实正文量和版号分版，给标题、导语与图件留出位置。全刊按[配图规则](visual.md)配 2–5 张图。图表依据已核数据，写明单位和截止时间。

## 输出候选

1. `mcp__desk__compose` 生成日期版。 `mcp__desk__prepare` 返回候选页路径及其指纹。发现正文漏源、内部文字或资源丢失时按具体错误回到对应编辑环节。
2. `mcp__desk__review(date)` 核对整期稿量、版序、配图和导出尺寸。发现硬伤时回到相关稿件或版位，修订后对新指纹重新校样。
3. 把候选路径、指纹和待核事项交给主编。主编按[发行验收](acceptance.md)逐版完成桌面与手机核对并填写终审记录。终审和量尺均通过后执行发行。
