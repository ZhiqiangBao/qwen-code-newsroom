# R1 · 线与采集口径

**读的人**：主编（派工、定选题）、`fetch`（照配额取材）。
四条线每期缺一不可；版面不够可加法律、市场、国际、体育，加料只为撑满加深，不许把四条线挤没。

| 线名（派工用） | 采集侧重 | 采集配额 |
|---|---|---|
| 人工智能 | 模型发布与评测数字、芯片与出口管制、算力电力投入、融资并购、监管与版权诉讼、国内大厂与创业公司动作 | 中国主体（厂商、监管、国产芯片与国产算力）≥2 条 |
| 科技 | 避开纯大模型：消费电子与秋季发布、半导体代工与光刻、航天发射、新能源车月度销量与装机、生物医药审批与临床读数、平台监管与数据泄露 | ≥1 条带硬数据的非 AI 产业项（销量／出货量／装机量／审批数） |
| 娱乐 | 华语女演员为主，可八卦；日韩欧美为辅。华语要有定档／开播／票房／收视／代言／奖项／维权 | 华语不少于半数，日、韩、美各 ≥1 条 |
| 动漫 | 日本动画为主（周末票房、新番与续篇发表、漫画周榜、动画公司业绩），美漫动画可补 1 条 | 日本不少于半数，国漫 ≥1–2 条（B站／腾讯视频／追光／彩条屋） |

**跨线归属判定**（一件事只归一条线，四路并行时防止重复深挖）：

- 模型能力、对齐与安全、评测分数、训练与推理成本 → **人工智能**。
- 芯片与晶圆本身的产能、价格、良率、代工与光刻、材料 → **科技**；但「某家 GPU／ASIC 厂商为训练集群供货」这种以模型训练为主语的交易与生态新闻 → **人工智能**。
- 票房、片单、艺人、流媒体内容 → **娱乐**；动画电影票房与剧场版 → **动漫**。
- 航天、生物医药、新能源车、平台监管 → **科技**。
- 判不准时按"读者会在哪一版找它"归线，并在回话里注明已归入他线，别的路径不要重复深挖。

- 派工只给线名（照上表写法）＋刊头日期＋希望补什么；要出重稿的那一路另标「重稿线」（预算更高，见 `.qwen/agents/fetch.md`）。
- **什么才算出处、直达地址、死路名单一律见 `desk/数据源.md`**，本条不重复；站点首页、频道页当出处即不合格。
- 缺的数字在素材里写「未获取」，不许编，不许拿往年数据顶替，不许把年度累计榜当当天消息。
