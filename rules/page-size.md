# 版面验收

纸宽 912 CSS 像素，以 6 栏为基准。一版一张纸，竖向叠放。逐版按最终校样验收。

| 检查项 | 合格线 |
|---|---|
| 导出宽度 | 912 × 导出倍率，误差不超过 10 设备像素 |
| 高宽比 | 1.35–1.75，定槽时瞄准 1.50–1.65 |
| 溢出与裁图 | 底部哨兵可识别，文字、图片和图注完整可见 |
| 栏高 | 同版各栏末行高差不超过一栏宽 |
| 版头与阅读顺序 | 刊头或内页版头在正文前，标题、导语和正文衔接明确 |
| 手机 | 在 320 CSS 像素宽度核对正文重排、导航和出处链接 |

任一项不合格时，先调整篇幅、版位或图位，再重新校样。机器量尺与主编终审的交接见[发行验收](acceptance.md)。
