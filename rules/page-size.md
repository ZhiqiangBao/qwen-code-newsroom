# R5 · 版面与尺寸

**读的人**：主编（判断是否填满）、`layout-check`（量尺与判定）。

**纸面**：宽 912px，按 6 栏排（每栏约 135px），栏线清楚、字距收紧、信息密度优先。单版观感接近 17.75″×30.5″ 的报纸页，不是网页长卷；一版一张纸，不要把全刊挤成一页。纸宽与栏数的**实现**在 `css/site.css`（改外观看 R4），本条只管**判定线**。

**导出**：`layout-review` 脚本会自己从 HTML 及其外链样式表读纸宽与纸色（`--paper`），并回吐 JSON 字段：`page_width_px`、`scale`、`expect_png_width_px`、`window_h_px`（导出窗口高，即溢出探测上限）、`measure[]`（每版 `px` 与 `ratio`）、`warnings`。量尺一律用这些回吐值，**不要把像素常数抄进别的文件**；脚本没有 `--output` 会直接报错，导出目录只能从 `rules/disk.md`「版面」行取。

| 检查项 | 合格线 | 判什么 |
|---|---|---|
| 导出页宽 | `expect_png_width_px` ±10 px | 是否被内容撑破或缩窄 |
| **高宽比** | **1.35–1.75** | <1.35 判 `[版面过短]`（纸没填满，等于半张纸）；>1.75 判 `[长卷]`（挤成网页） |
| 底部哨兵 | `warnings` 为空 | 报「底部不是哨兵绿」即判 `[溢出]`：该版高度撞到 `window_h_px`，内容超出纸面 |
| 栏高齐整 | 同版各栏末行高差 ≤1 栏宽 | 超出判 `[留白]`，指出哪一栏 |
| 图不裁切 | 海报／剧照走 `contain` 完整 | 切边判 `[裁图]` |

**版面是否填满以高宽比为准绳**：字数达标而高宽比不合格，说明排版失衡；两者都不达标就是缺稿——缺稿按 R2「内容量与重稿」回去补稿，不许拉伸。

**禁止**：用大字距、空栏、`min-height` 制造版面高度。那是把问题藏起来。
