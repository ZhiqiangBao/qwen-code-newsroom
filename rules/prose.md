# R3 · 文体（我们写新闻，不写读后感）

**读的人**：主编（写稿前必读、交校对前自查）、`copy-check`（判 `[文体]`／`[元叙述]`）。

**总纲：事实组织段落，出处承担权威，形容词不参与论证。** 病灶只有一个来源——把编辑部的取材台账当成文章结构：读者看到的应是新闻，不是我们的目录、提纲和感想。

1. **段落准入**。每段必须含至少一个外部可核的具体项：日期、金额、人名、逐字引语、位次、同比环比。把段中所有评价句删掉后什么都不剩的，整段重写，不许就地润色。
2. **内部标识零出现**。读者文本里禁止出现版号互见（「A1」「B2」「C1 那一版里」「B3 报道的」「相关论述见 E1 社论」）、`desk/` 与 `rules/` 路径、子代理名、流程自述、取材过程交代。**例外**：导航条、「今日各版」索引、一期速查表——那是目录，本来就该标版号。
3. **评论与专栏不得引用自家版面**。要复用别的版面的事实，必须重述该事实并给外部原始出处（媒体名＋日期）。并置不是论证：几条事实摆在一起，得说清中间那条可核的因果链是谁说的、有没有第三方数据。
4. **判断句式配额**。「不是 A，而是 B」每篇 ≤2 次，且 B 必须紧跟具体证据；「值得注意的是／真正值得盯的是／关键在于／这句话的巧妙在于／这本身就是新闻」每版 ≤2 次，能删则删，把取舍交给事实排列和引语选择。对偶排比每篇 ≤1。
5. **文体三格分立**。消息＝第三人称＋外部出处，只交代谁在何时做了什么，正文内不许出现本报判断（「本报的判断是……」属违规）；配评＝另起一节显式标注（`<p class="kicker">短评 · ××</p>`），篇幅短；评论／专栏＝可第一人称、可判断，必须有署名落款（`—— 本报动漫组`、`—— 主编`）。
6. **议论连接词不算证据**。「所以」「由此推出」「这一点必须说透」「综上」之后若没有可指认的来源或数字，改成事实陈述或直接删。
7. **按语只能落在具体事实上**。「本期主张」「编者按」不许写抽象对立与口号（「口径比数字更需要交代」「答案不在发布会，在条款里」），要落在日期、金额、位次上，一句话讲清这条为什么值得放头条。
8. **内部信息一律不上版**。「未获取」是主编与素材之间的内部通信。读者版里数字缺失只允许在 `src-note` 或正文句中以「××：未获取」一行带过；**禁止**「未获取清单」「本期没查到的」「取材说明」「编排说明」这类成节、成标题、成短评的自我交代，禁止编辑台自述入句（「故本版不作行业排名结论」「本报也不替读者决定」）。交付物里不得有对话痕迹或元叙述。

反例（2026-09-01 真实见报句，照此自查）：「C1 那一版里，信越化学……」「B2 刊载的 Anthropic 披露中……」「把这几件事并置，本报的判断是一句话」「同样一句话也适用于 C1」。
