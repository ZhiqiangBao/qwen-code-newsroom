# 样式与配图

头版突出头条，正文版保持清楚的标题与段落次序，快讯按独立文章分块。长标题以自然换行和左对齐为主。单栏最长文特别检查阅读行宽。给标题和正文留出适当空间，正文不靠强行压缩字距填版。

全刊配 2–5 张图。图位记录 `article`、`id`、`class`、`src`、`cap` 与 `alt`。优先使用获准使用的公开成图，灰度上版，注明具体出处。根据已核数据制作的图表注明数据来源。示意图标明性质，生成图写明「人工智能生成／本报制图」。

图片与对应稿件一起排。海报、剧照使用完整比例，人物小图使用 `wrap`。空图位不计配图。主编打开实际校样核对图片内容、图注、版权或使用条件及可辨认度。
