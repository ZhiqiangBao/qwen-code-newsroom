# R4 · 样式与配图

**读的人**：主编（排版与生图）、`fetch-poster`（登记图注口径）、`image-check`（判人像与廉价感）。

## 样式表（改外观只改这一个文件）

全刊样式在 **`css/site.css`**；每期见报 HTML 的 `<head>` 里只留一行 `<link rel="stylesheet" href="css/site.css" />`，**不许把系统级选择器或尺寸整份抄回内嵌 `<style>`**。字体、颜色变量、栏宽、`.flow` 列数、图片灰度、表格线都在这张表里改。

样式表是**词汇表不是模板**：系统级那几样每期必须一致，但**版式怎么搭仍由主编每期自己设计**——栏式、图的摆法、标题字号档、要不要时间线／引语块／侧栏框／统计表、版数与节次详略，CSS 一律不规定。手上有哪些积木，见本条末节「版式类名」。

**要新积木就加 class，别写进某一期**：想做「通栏大字导语」这类新元素，把 class 加进 `css/site.css`（一处新增，往后每期可复用）；写进单期内嵌 `<style>` 就会长出第二份、第三份副本。

**本期局部覆盖（允许，三条硬约束）**：某一期确实需要一次性微调时，可以在该期 HTML 里加一小段 `<style>`，但必须——

1. 选择器限定在本版范围内（带上该版的 `id`，或本版专属 class），不许全局重定义；
2. 不碰系统级：`--*` 变量、`.page`、`.flow` 的栅格基数、字体栈、灰度滤镜——要动就动 `css/site.css`；
3. 在 `desk/版式/YYYY-MM-DD.md` 记一行为什么覆盖，不留匿名特例。

新增一期：照上期的 `<head>` 结构复制（含那行 `<link>`），只改 `<title>` 与报头文字，不要重新手搓 CSS。版面导出脚本会在导出时自动把这张表内联进临时页面，所以改完 `css/site.css` 不必改任何脚本。

**改纸宽要连改三处**（前两处在同一文件内）：`css/site.css` 的 `.page{width:min(<N>px,…)}` 与 `.flow`／`.flow.n2`／`.flow.n4` 的 `column-count`，再加 `rules/page-size.md` 的纸宽数字——否则纸变宽了、6 栏却还按旧宽度排。

## 字体与文本样式

中文 Noto Serif SC；西文与数字正文 Source Serif 4；标题 Newsreader（字体栈里写在 Noto 之前，别让西文被中文字体接管）；眉题、导航、导读、脚注用 Libre Franklin。正文首行缩进约两字，两端对齐，字距为零。

## 数字写法

钱、人数、百分比、年龄、日期一律阿拉伯数字（`$2`、`70%`、`2 小时`、`2026 年 8 月 31 日`），不写「二美元」「七十亿」「七成」。日文汉字数字转写为阿拉伯数字，保留原口径与单位。

## 成图优先

公开、有格调的成图——片方／平台／官方账号放出的海报、剧照、主视觉、新闻稿配图，机构发布的现场照片。下载到见报图目录，**做成黑白（或版上灰度）再上版**，图注写「公开资料」。不要把图留在桌面或 `.qwen` 里。禁止彩色原图直贴、粉丝手机抓拍、营销抠图、霓虹大头、假人脸。剧集／电影／动画有官方海报就用海报，不要再生成一张假的。

## 生成图

成图补不到、或属人物头像，才用内置 `image_gen`（参数只有 `prompt` 与可选 `size`，如 `1536*1024`；不用 skill、不用 shell 脚本、不调 API），出图后 copy 进见报图目录，图注写「人工智能生成／本报制图」。

人物一律小幅素描头像，属合理使用，**必须像本人**：提示词直接点名（「中国女演员王鸥的报章人物素描头像，要像本人」），不接受「某三十多岁女性」这类模糊替代——宁可不出，不出不像的。

每张图出完派 `image-check`（任务里写图片路径，头像另写姓名），禁止主编 `read_file` 图片。回 `通过` 才上版，否则按 `问题：` 重出，不许将就。

## 版式类名（主编手上的积木；完整选择器与尺寸只在 `css/site.css`）

**系统级（每期一致，覆盖时不许碰）**：`.page` 一版纸面、`.flow` 的栅格基数、字体栈与 `--ink`／`--paper`／`--hair`／`--mute` 颜色变量、图片灰度滤镜、`.nav` 导航、`.folio`／`.foot` 版号与页脚。

**设计词汇（每期自由挑用，可同版混用）**：

- 栏式：`.flow`（3 栏）、`.flow.n2`（2 栏）、`.flow.n4`（4 栏）。
- 图：`figure.wrap`（文字绕排）、`figure.wide`（通栏）、`figure.poster`（海报完整不裁）、`figcaption`。
- 标题与导语：`.kicker` 眉题／栏目条、`.hed` 标题、字号档 `.xxl`／`.xl`／`.l`／`.m`／`.s`、`.deck` 导读、`.leadhead`、`.drop` 首字下沉、`.lede`、`.feil` 报眉条、`.by` 署名。
- 结构化件：`.tl` 时间线、`.q` 引语块、`.box` 侧栏、`.ed` 编者按框（内含 `.cols`／`.sig`）、`table.stat`（`td.n` 为数字列）、`.idx` 索引、`.mini` 小字块、`.ni` 简讯、`.band` 分段带。
- 线与空隙：`.hair` 细线、`.dbl` 双线、`.vr` 竖线、`.clear` 清除浮动、`.rule`。
- 交代：`.src-note` 出处与缺失、`.jump` 跳转、`.just` 两端对齐。

想做列表里没有的元素（例如「通栏大字导语」），把 class 加进 `css/site.css`，再回这里补一行；不要在单期里手搓。
