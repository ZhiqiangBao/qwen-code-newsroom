# 样式与配图

头版突出头条，正文版保持清楚的标题与段落次序，快讯按独立文章分块。长标题以自然换行和左对齐为主。单栏最长文特别检查阅读行宽。给标题和正文留出适当空间，正文不靠强行压缩字距填版。

全刊配 2–5 张合格新闻图片，图表不计入，且不得作为文章配图。优先使用已公开发布并获准使用的官方海报、剧照、主视觉或机构照片；只有无法取得适用公开成图时，才使用内置 image_gen 生成替代图。图位记录 `article`、唯一 `id`、`class`、本地非空文件 `src`、`kind`、`origin`、`source_url`、`cap` 与 `alt`。`kind` 只能是 `official-photo`、`official-art`、`generated-illustration` 或 `generated-portrait`；`chart` 不得作为发行配图。官方图片须给出真实 HTTPS 来源页，图注含「公开资料」及可点击来源链接；生成图片的 `origin` 须说明无法使用公开成图的原因，图注写明「人工智能生成／本报制图」。数据图表应放在配图之外并注明数据来源。

图片与对应稿件一起排。海报、剧照使用完整比例，人物小图使用 `wrap`。空图位不计配图。主编终审前，按 `.qwen/agents/image-check.md` 对每张图独立目视核验内容与稿件对应、来源及使用条件、图注和可辨认度；主编再打开实际校样核对。
